Reviewer Evaluation Guide

8-turn test suite validating all core voice agent capabilities

1 Greeting & Tool Call
"Tell me about PM Awas Yojana and what benefits it provides."
Validates proactive greeting, search_knowledge tool dispatch, and initial latency metrics.
2 Barge-in & Lang Switch
[Interrupt while agent speaks] "Mujhe Hindi mein samjhao."
Validates client barge-in detection, TTS abort, generation increment, and switch to hi-IN.
3 Context Memory
"Iske liye kaun-kaun se documents chahiye?"
Validates context persistence of PMAY without restating scheme name + get_required_documents.
4 Cross-Scheme Switch
"What are the eligibility criteria for PM-KISAN?"
Validates scheme context pivot, automatic language switch back to English, and check_eligibility.
5 Code-Mixing / Hinglish
"MNREGA ka application form kaise bharte hain?"
Validates mixed-language STT parsing, Hindi response constraint, and get_application_steps.
6 Entity Extraction
"I want to check my application status. My ID is APP4."
Validates regex/slot extraction of application ID 'APP4' and get_application_status tool lookup.
7 Scheme Reset & Hindi
"Mujhe Atal Pension Yojana ke baare mein batao."
Validates workflow state reset, RAG search against Atal Pension knowledge, and Hindi Devanagari TTS.
8 Callback Booking
"I want to book an officer callback."
Validates date/time slot parsing, book_human_callback dispatch, and confirmation reference generation.
